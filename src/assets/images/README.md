# Loixrang Bank — Login UI Assets

## Included
- `logo-mark-blue.svg` — blue/purple bank building logo only, no text
- `icon-login-white.svg` — white login/lock icon
- `icon-secure-white.svg` — white security icon
- `icon-user.svg` — username field icon
- `icon-wallet.svg` — balance field icon
- `icon-eye.svg` — balance visibility icon

All assets are SVG and can be resized without quality loss.

## Color Palette

### Primary
- Primary Purple: `#5B35D5`
- Deep Purple: `#3E2AA8`
- Hero Gradient Start: `#2E218E`
- Hero Gradient End: `#6240D8`

### Backgrounds
- Page Background: `#F7F8FC`
- White: `#FFFFFF`
- Soft Lavender: `#F1EEFF`

### Text
- Primary Text: `#17213D`
- Secondary Text: `#68779B`
- Placeholder: `#7C89A8`

### Borders / Effects
- Input Border: `#DDE2EF`
- Soft Border: `#E8EAF2`
- Card Shadow: `rgba(36, 35, 95, 0.12)`
- Purple Glow: `rgba(91, 53, 213, 0.18)`

### Icons
- Login Icon: `#FFFFFF`
- Secure Banking Icon: `#FFFFFF`
- Field Icons: `#68779B`
- Bank Logo: `#5B35D5`

## Typography
Recommended font: **Inter**

Weights:
- 400 — body / placeholders
- 500 — labels
- 600 — buttons
- 700–800 — headings

Fallback: `Inter, Arial, sans-serif`

## CSS-made elements
The purple gradients, circles, dotted patterns, rounded cards, shadows, and other decorative effects can all be recreated with CSS; they do not need image files.
